# 员工登记与创建账号

入口统一在注册窗口：勾选 **Personne extérieure à l’entreprise** 时仅保留姓名、必填邮箱和账号组织权限，不提交名册、合同或社保号；通过共享 `adminApi.create` 调用现有 `/create-user` 建号。Administration 暂不显示独立建号按钮。取消勾选回到员工登记流程，员工可选择是否同时建号。外部账号仍由既有账号权限管理，不凭外部身份自动授予管理权限。

在 Registre du personnel → Enregistrer un salarié 中输入员工资料和邮箱，勾选 **Créer aussi le compte de connexion**，即可选择权限、部门、管理部门和直接负责人。默认为 Standard/Employé；普通 Admin 无权授予 Super Admin。账号人员类型沿用员工登记，不重复填写。

不勾选时仅登记员工，邮箱选填。新注册窗口不再显示关联已有账号的板块；已有档案仍可在详情或 Administration 中维护账号关联。接口继续兼容已有账号关联，但与同时建号互斥。新建成功后自动关联员工档案，并按现有合同规则同步完整的 CDI 或有预计结束日期的合同；仅填写入职日期不会编造合同结束日期。

账号、档案、权限审计及合同写入使用同一个事务。中途失败全部回滚。提交成功后尝试发送一次邮件：密码由后端生成 8 位大写字母与数字，只持久化密码散列；不会写入响应或名册审计。邮件失败保留账号，界面明确提示不要重复创建，可使用忘记密码流程。账号邮箱被占用时拒绝新建，不自动关联或修改旧账号权限。

名册新增可选 email 列，通过增量迁移添加，不覆盖历史数据。不修改已关联账号的登录邮箱；该操作仍在账号设置中完成。Excel 模板列保持原样。

本地测试入口显式启用建号，welcome mail 强制禁用，不发送真实邮件；其他快照环境默认关闭。正式环境继续复用已有 SMTP 配置。此功能当前未部署到线上。

验证：92 项后端回归（含真实本地 MySQL 连接级临时表事务测试）、54 项前端测试、TypeScript、lint 和生产构建通过。检查了成功关联、密码散列、提交后发信、重复邮箱、越权拒绝、负责人角色、审核失败完整回滚、邮件失败保留记录，以及不建号的登记兼容。浏览器验证仅操作空白表单，没有新增真实员工、账号或发送邮件。
