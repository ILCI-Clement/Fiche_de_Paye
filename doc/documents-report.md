# Documents 模块开发报告

日期：2026 年 10 月 9 日

Documents 已从单一交通凭证上传页面扩展为按月管理文件的模块，支持类型分类、归档箱、卡片展示及勾选批量下载。目前业务功能已部署；代码模块化重构保存在本地，尚未部署。

## 开发目标

员工集中提交发票或报销凭证，管理员按所属月份整理、下载并交给财务。通过明确的月份提示、分类标签和批量导出，减少错放月份、逐个下载以及文件列表占用过多页面空间的问题。

界面名称为 Documents。原页面地址 `/TransportReceipts` 和后端 `/transport-receipts` 接口保留，以兼容已有访问入口。

## 已开发功能

| 功能 | 当前实现 |
| --- | --- |
| 文件上传 | 支持 PDF、JPG、JPEG、PNG；每次上传一个文件，后端上限为 10 MB，并检查文件扩展名及格式头 |
| 文件类型 | Transport 或 Autre；选择 Autre 时必须填写具体类型，例如餐费或设备 |
| 月份绑定 | 默认采用页面当前月份；上传前显示目标月份，提交按钮也标明月份，可单独调整上传月份及年份 |
| 月份修正 | 管理员可以修改已上传文件的绑定月份，无需重新上传 |
| 月份显示 | 文件名后加粗显示法语月份与年份；原始文件名和单份下载文件名不因此改变 |
| 月份联动 | 顶部和文件列表上方都有月份与年份选择器，使用同一月份状态 |
| 类型识别 | Transport 使用蓝色标签，Autre 使用橙色标签，历史未分类文件显示灰色标签 |
| 类型过滤 | 支持 Tous、Transport、Autre、Non renseigné，通过下拉框筛选 |
| 文件视图 | 待处理与 Archives 分开显示，归档文件不会混入默认待处理列表 |
| 紧凑布局 | 电脑端每行三张卡片；标题、数量、归档切换和类型过滤横向排列；管理操作可展开 |
| 单份下载 | 点击 Préparer 后提供 Télécharger 下载按钮 |
| 批量下载 | 勾选文件或全选当前筛选结果，准备 ZIP 后下载；归档箱也支持 |
| 删除确认 | 有权限的用户删除前需要再次确认 |

月份统计包含该月待处理和归档文件；筛选结果数量则仅计算当前文件夹及类型下的可见文件。

## 使用流程

### 上传文件

1. 登录个人账户，进入 Documents。
2. 选择应归属的月份和年份。
3. 选择 Transport 或 Autre；Autre 需填写具体类型。
4. 员工及经理自动绑定本人；管理员可以选择代传的人员。核对页面提示的目标月份。
5. 选择文件，点击标有月份的提交按钮。
6. 上传成功后，文件出现在对应月份的待处理列表中。

例如：十月上传九月的交通凭证，应将文件绑定到 Septembre 2026。系统分别记录绑定月份与实际上传时间，列表依据绑定月份归类。

### 整理与批量下载

1. 管理员切换到目标月份。
2. 选择 À traiter 或 Archives，再按类型过滤。
3. 勾选文件，或点击 Tout sélectionner 全选当前可见结果。
4. 点击 Préparer le ZIP。
5. 准备成功后，点击 Télécharger le ZIP。

切换月份、文件夹或类型会清空选择并失效旧的 ZIP，避免下载上一组筛选结果。ZIP 内文件名包含所属账户、类型、记录编号及原始文件名，减少同名覆盖。

当前限制为所选原文件累计不超过 100 MB。某个文件读取失败或权限检查不通过时，不提供缺少文件的部分 ZIP，需要调整选择或重试。

## 文件存储与生命周期

文件内容保存在服务器私有目录，默认路径为 `/var/lib/presence-app/transport-receipts`，可通过 `PRESENCE_TRANSPORT_RECEIPTS_DIR` 配置。服务器使用随机文件名保存，用户看到的是原始文件名。

MariaDB 的 `transport_receipts` 表保存文件编号、所属账户、上传者、原始和存储文件名、格式、大小、类型、绑定月份与年份、上传时间及归档信息。

文件没有自动到期删除机制。归档只修改记录状态，文件继续保留并可下载；删除操作会移除数据库记录并删除服务器文件。长期保存的可靠性仍取决于磁盘和备份机制，本次报告没有核实周期自动备份与恢复演练。

文件通过需要登录认证的接口下载，没有在页面中直接暴露私有目录作为公共下载路径。

## 当前权限

| 角色 | 查看与下载 | 上传 | 管理操作 |
| --- | --- | --- | --- |
| Admin | 全部文件，支持单份及 ZIP 下载 | 可为已注册账户上传 | 可归档、修正月份、删除 |
| Responsable 或 Manager，且无 Admin 权限 | 本人及后端允许的团队范围 | 只能给自己的账户上传 | 不能归档、修正月份或删除 |
| 普通账户 | 绑定给自己账户的文件 | 只能给自己的账户上传 | 可删除自己上传的文件，不能归档或修正月份 |

普通账户上传时可选其他账户，是当前需要优先收紧的授权范围。上传权限和查看权限并不相同：为其他账户上传后，并不因此获得查看该账户文件的权限。

## 代码模块

| 本地模块 | 职责 |
| --- | --- |
| `pages/TransportReceipts.py` | 上传、月份选择、类型和归档过滤、列表布局 |
| `document_ui.py` | 文件卡片、管理操作、勾选及 ZIP 下载控件 |
| `document_downloads.py` | 鉴权读取文件、生成 ZIP、文件名清理与容量限制 |
| `period_selector.py` | 法语月份名与多个选择器联动 |
| `api_client.py` | 认证头、请求及错误解析公共工具 |
| `backend/documents.py` | 文件接口、上传校验、权限、月份元数据、归档与删除 |

2026 年 10 月 14 日已整体部署模块化页面与后端，包括 `document_ui.py` 与 `backend/documents.py`。后续更新仍须同步入口与依赖模块，不能只替换单个页面。
