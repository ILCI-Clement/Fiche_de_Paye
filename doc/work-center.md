# 资料就绪与待办中心（本地待发布）

Admin / SuperAdmin 和 Responsable 登录后默认进入 Tableau de bord；普通员工仍进入请假页面，不获得待办或资料汇总接口权限。

## 使用

首页 À traiter 汇总待审批请假、待跟踪签署、已签 PDF 待回收、资料待核对。按类型或姓名搜索，每页最多 8 条；点击操作可直接定位请假详情、对应月份的签署页、账号或员工名册。就绪提示也显示在 Mon équipe 姓名下方和 Administration 所选账号顶部。

资料就绪按选定月份检查有效合同；姓名、员工邮箱、直接负责人的有效状态与联系信息单独检查。仅 Admin 可查看名册是否关联、已归档或基础资料未完成。名册未关联或缺项不阻止创建考勤。“资料已就绪”仅表示已检查的前提具备，实际工时表导出和发送仍沿用原有完整校验。没有当月合同的记录显示“待核对”，不自动创建或更改合同；部门负责人若不是直接负责人，不能通过该入口补录合同。

请假和签署待办覆盖所有日期；月份选择只作用于资料合同检查。仅正式签署进入待办，不汇总 Sandbox。已签 PDF 正在回收与回收失败会使用不同描述；待办不自动重发签署、发送邮件、审批或重试回收。

## 接口与权限

`GET /dashboard/work-center?month=1..12&year=2000..2100`，省略日期时使用巴黎当前月份。纯读取，无迁移或新增业务表，响应 `Cache-Control: no-store`。

- 每次重新核对数据库中的账号状态、会话版本、角色。普通账号 403，失效会话 401。
- 就绪账号范围沿用考勤管理权限，仅有效且含 Employe 角色的账号。部门管理权限不等于请假审批权限。
- 请假只列出未归档、待审批且当前有权审批的记录；Responsable 仅直属下属。
- 签署复用 `signed_fiche_scope`：Admin 可看全员；负责人必须同时是当前直属负责人和当次签署负责人；本人记录沿用原规则。未知历史负责人不推测，已完成归档和已取消记录不列待办。
- 负责人不查询员工名册。Admin 的完整度查询只读取所需姓名、关联信息及字段是否已填写的布尔值；不返回住址、出生日期、工作证件、社保号或加密内容。
- 账号表与签署表关联使用二进制 ID 比较，兼容混合 utf8mb4 排序规则，与 Python 文件鉴权的精确账号匹配一致。

前端 `workspaceNavigation.ts` 提供带序号的目标；所有跨页动作经过现有草稿保护。目标页只更新筛选/选择，不自动保存或创建记录。首页和团队页只在可见时定时刷新待办（60 秒）；请假决策和已有管理保存会使缓存失效，也可手动刷新。
