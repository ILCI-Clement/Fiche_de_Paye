## 行为

- 账户负责人选填，未填写不产生资料缺失提示；主动绑定的失效负责人仍提示。
- Super Admin 不要求员工名册、合同、部门或负责人等业务资料；新建 Super Admin 使用仅建账号流程。已有员工资料和业务历史保留。
- Super Admin 可给自己降级为 Admin、Employé 或符合部门规则的 Responsable，但必须保留另一个有效 Super Admin。停用或删除登录资格的账号不计入。
- 角色变更与审计在事务中保存，保留 users 写锁及最后一个 Super Admin 保护。撤销旧会话、记住登录和恢复凭据，当前前端强制返回登录；其他 Super Admin 的目录隐藏规则不变。
- Administration 账户详情右下角固定 Enregistrer 按钮，提交同一个组织表单，支持折叠板块下修改权限后的确认和保存。移除折叠板块内的重复保存按钮。
