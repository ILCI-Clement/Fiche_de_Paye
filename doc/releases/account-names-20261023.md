## 发布内容

- 创建账号分别必填名、姓，后台同样校验；使用邮箱登录，未指定旧式标识时生成稳定的随机账号 ID。同名员工互不影响，密码继续保存为 bcrypt 哈希。
- 姓名显示优先关联名册的结构化名/姓，再用账号名/姓、旧名册全名和邮箱前缀；不猜测拆分旧姓名，不改历史身份关联。
- 发布此前本地完成的员工登记升级：新档案基础信息与入职日期必填；外籍、临时工及青年/学徒允许同时勾选并条件校验；旧资料逐步补全。
- 实际离职日期独立于预计合同结束日期，Excel 的 Sortie 使用实际离职；旧预计结束日期不自动转换。
- 包含本地回归修复：模型级社保号校验异常脱敏、首次关联合同重复任职防护、入职与出生日期检查、法语日历标题。
- 当前运行代码移除旧 Streamlit 专属模块，保留共用日历规则及文件生成；新旧 API 继续识别历史数据和账号状态。
