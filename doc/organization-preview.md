## 当前界面

Direction Générale 位于顶部，William 在该部门内显示；其余活跃 Groupes 用独立响应式卡片展示，不画部门连线。卡片包含部门名称、负责人和成员，负责人也在成员名单内。无负责人显示待指定，无成员显示空状态。

架构默认折叠，无拖动、缩放或固定画布高度。容器宽度不超过 780px 时两列，不超过 480px 时单列，其余三列。无姓名采用邮箱 @ 前部分。未分配或只属于停用部门的人员另列；历史多部门、多负责人数据保留并提示。

所有登录账户可读取基础架构。普通员工可以查看自己活跃部门的基础名单；Admin 和 Manager 保留原人员表格及后端授权范围。目录不暴露完整邮箱、合同或文件，不扩大人员编辑权限。

## 脚本和预览

详细职责、入口与依赖图见 [脚本职责与应用入口](architecture.md)。正式页面不再包含虚构数据模式、预览隐藏控件或模拟账号选择。

8503 是独立本地预览入口，读取 `.local-test/organization_data.json` 中的只读快照。模拟账号选择仅用于观察本部门名单，不是实际鉴权。快照、预览脚本和截图不部署、不提交。8502 是完整本地应用，连接生产 API 时操作会影响真实数据。

早期 ECharts 原型保留用于历史比较，不在当前页面依赖链中；当前卡片不加载 ECharts。

## 验证与边界

2026-10-14 新增 14 项目录和页面测试，完整回归共 78 项通过。测试覆盖登录、角色读取、服务端部门范围、查询参数无法越权、敏感字段裁剪、连接释放、HTML 转义、旧冲突保留、默认折叠和页面分支。浏览器已检查折叠与展开，7 个真实部门快照正常显示；此前已观察宽、中、窄屏布局。

本次仅发布只读架构和员工本部门名单。单部门归属、单负责人强制约束、负责人变更自动调整权限，以及 Admin 持久化测试账号标记/隐藏仍待实现。旧数据不自动清理；考勤签署仍使用原员工负责人规则。发布结果见 [重构记录](refactoring.md)。
